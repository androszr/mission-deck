Installing Mission Deck

A step-by-step guide to running Mission Deck on your computer. Go through the steps in order - it takes about fifteen minutes.

Before you start

You need Visual Studio Code and a modern browser. You do not need an encryption key or any token to begin - the setup wizard asks for them at the end, and every one of them is optional.

0Install the tools

  • Visual Studio Code - the editor you open the project in (code.visualstudio.com).
  • Node.js 24 - the runtime. On macOS install it with Homebrew, not the .pkg installer: the latter needs an administrator password for every global tool install.
  • Git - version control. On Windows keep the installer's default options (Git Bash comes with it, and the git hooks and Claude Code need it).
  • Python 3.10+ - used by helper scripts. On macOS the command is python3, on Windows python or py.
macOS
brew install node@24 git python
Windows
winget install OpenJS.NodeJS.LTS Git.Git Python.Python.3.12
What is Homebrew? On macOS the brew commands need the Homebrew package manager. If you do not have it, install it once with the command from brew.sh.
After installing, close and reopen the terminal (preferably the whole of VS Code) so the system sees the new commands. Check with node -v (it should start with v24), git --version and python3 --version / python --version.

1Get the code

git clone https://github.com/androszr/mission-deck.git

Put it somewhere safe on a local disk - outside OneDrive and iCloud.

  • Windows: preferably straight on C:\ (for example C:\mission-deck).
  • Mac: in your home folder (for example ~/Projects/mission-deck).
Why does it matter? OneDrive and iCloud folders sync continuously. The app creates a lot of files that should not sync - it would slow the machine down and could corrupt data.

2Open the folder in Visual Studio Code

  1. Choose File → Open Folder...
  2. Pick the project folder and press Open.
  3. When asked "Do you trust the authors of the files in this folder?", press Yes, I trust the authors.
Use a clean window. Open the project in a new VS Code window - do not add it to a workspace with other folders. Several folders in one window make terminal commands run in the wrong directory.

3Install the dependencies

Choose Terminal → New Terminal and run:

npm install
npm run setup

npm run setup downloads, once, the browser used by visual verification and builds the code map for Claude Code. You do not create or edit a .env file to start.

4Start the app

npm start

The server starts - keep this terminal open while you work. After a moment the browser opens Mission Deck by itself, on the first run straight on the setup wizard.

No browser window? Open one yourself and go to localhost:3001.

5The setup wizard

On the first run Mission Deck opens on a wizard that walks you through setup:

  • Environment - checks that Node, Git, Python, Bitwarden CLI and Claude Code are present; what is missing installs with one button.
  • Bitwarden (optional) - unlocking a vault gives the app its tokens (Jira, Confluence and others) without pasting them anywhere.
  • App repository access - a token the app uses to recognise you and fetch updates, if you run it from your own Git host.
  • Encryption keys - paste the key your team gave you; the data decrypts automatically.
  • Team data - pulls the team data repository, if you configured one.
  • Update - checks for and installs the newest version with one click.
  • Academy - unlocks when the rest is done and leads you to building your first module.
Why an encryption key? Team data lives in its repository encrypted (AES-256-GCM), so it is unreadable without the key. The wizard saves the key locally in .encryption-key, readable by the owner only - it never goes into .env or anywhere off your machine.

You can return to the wizard at any time from Start here in the side menu, just above Settings.

6Bitwarden CLI (optional)

If your team keeps tokens in Bitwarden, install and log in to the CLI once:

npm install -g @bitwarden/cli
bw config server https://vault.bitwarden.com
bw login

Logging in is a one-time step. Unlocking the vault (typing the password) then happens inside Mission Deck: Settings → Keys or the Bitwarden pill in the top bar.

7Claude Code

macOS
brew install --cask claude-code
Windows
npm install -g @anthropic-ai/claude-code

Then run claude in the VS Code terminal, in the project folder. On the first run a browser opens to sign in to your Anthropic account. From then on Claude Code works in the terminal with the whole project as context.

Done

Mission Deck is installed. You now have two places to work: Mission Deck in the browser - dashboards, data, reports and every module - and Visual Studio Code with Claude Code, where you build new modules and grow the app.

To learn how, open the Academy from the dashboard tile, or go straight to http://localhost:3001/#academy while the app runs.

Stuck? See docs/troubleshooting.md, or open an issue on the project's GitHub page.
