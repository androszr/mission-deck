Server tokens and your identity. Read-only - change the values in Bitwarden.

The Claude Code agent crew - who does what in which skill, which model drives it and how to read its brief. Picking a model overrides the default model in the agent frontmatter.

Skills are how Mission Deck works. Each card says how to invoke the skill, what it does and what it leaves behind; the instructions open in a preview. The description, phases, agents and commands are read straight from the files in .claude/skills/, so a card cannot drift from its skill.

Team directory: first name, last name, role, team, e-mail and photo. Saved to the data repository and shared with the team on sync.

Add-ons installed locally from the modules/ folder: enable, disable, remove or hand one to a colleague as a zip file. Every change takes effect only after a server restart.
