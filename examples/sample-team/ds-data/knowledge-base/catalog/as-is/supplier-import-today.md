## The flow

1. A supplier emails a spreadsheet.
2. Someone in operations cleans the columns by hand.
3. A developer runs a script to load it.
4. Prices are checked in a second spreadsheet.

## Pain points

Every step waits for a person. A typical import takes three days and fails about one time in four.
